# Сценарий игры <!-- omit in toc -->

Игрок открывает поле, скрывающее спящих пёсиков и котиков. Цель — найти всех котиков, не разбудив ни одного пёсика. Если под открытой клеткой оказывается пёсик — игра окончена. Если все клетки без пёсиков открыты — победа.

## Игровое поле

Поле представляет собой сетку закрытых клеток. Клетки бывают трёх видов:

|         Иконка          | Описание                                                                                                                    |
| :---------------------: | :-------------------------------------------------------------------------------------------------------------------------- |
|  ![dog](icons/dog.svg)  | **Пёсик** — мина. Спит под закрытой клеткой. Если открыть такую клетку, пёс просыпается и игра заканчивается поражением.    |
| ![fish](icons/fish.svg) | **Рыбка-флажок** — метка, которую игрок ставит правым кликом на подозрительную клетку. Помогает не открыть пёсика случайно. |
|  ![cat](icons/cat.svg)  | **Котик** — открытая безопасная клетка без соседних пёсиков. Когда все такие клетки собраны, игрок побеждает.               |

Если рядом с открытой клеткой есть пёсики, вместо котика отображается цифра — количество пёсиков среди 8 соседних клеток.

## Управление

| Действие                             | Результат                                                                                                                                          |
| :----------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Клик** по закрытой клетке          | Открыть клетку. Если пёсик — поражение. Если пусто — волна автоматически открывает соседние клетки.                                                |
| **Правый клик** по клетке            | Поставить или убрать рыбку-флажок. Зафлаженную клетку нельзя случайно открыть.                                                                     |
| **Клик** по открытой клетке с цифрой | **Хорд**: если рядом уже расставлено столько флажков, сколько указано на цифре, открывает все оставшихся соседей. Удобно для быстрого прохождения. |

Первый клик всегда безопасен — пёсики расставляются уже после него, гарантированно обходя выбранную клетку и всех её соседей.

## Уровни сложности

| Уровень       |  Поле   | Пёсиков |
| :------------ | :-----: | :-----: |
| **Котёнок**   |  9 × 9  |   10    |
| **Кот**       | 12 × 12 |   20    |
| **Дикий кот** | 16 × 16 |   40    |

Переключение уровня доступно в любой момент и немедленно сбрасывает текущую игру.

## Интерфейс

В панели управления отображаются:

- **Счётчик пёсиков** — сколько пёсиков ещё не отмечено флажками (мины − флажки).
- **Таймер** — время с первого клика до окончания игры, максимум 999 секунд.
- **Кнопка рестарта** — начать новую игру с той же сложностью.

По окончании игры появляется баннер:

- **«Мяу! Победа 🐟»** — если все безопасные клетки открыты.
- **«Ой, разбудили пёсика 🐶»** — если открыта мина. Все пёсики на поле раскрываются.

Клик по баннеру начинает новую игру.
